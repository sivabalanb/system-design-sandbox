# Diagram Tips for System Design

- **Tools**: Use Excalidraw (free, simple) or Draw.io (integrates with cloud).
- **Components**: Show clients, servers, DBs, caches, load balancers.
- **Arrows**: Indicate data flow (e.g., API requests, DB queries).
- **Keep It Clear**: Avoid clutter; label key parts.
- **Export**: Save as PNG/SVG for GitHub compatibility.
