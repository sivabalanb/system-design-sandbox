# How to Contribute

Want to join the System Design Sandbox? Here’s how:

- **Suggest a Problem**: Open an issue with a system design scenario (e.g., “Design a food delivery app”).
- **Improve a Design**: Submit a PR to `problems/*/vN.md` with refinements or new versions.
- **Add Resources**: Update `resources.md` with books, videos, or tools.
- **Guidelines**:
  - Keep it beginner-friendly.
  - Explain trade-offs clearly.
  - Use markdown for consistency.

Questions? Open an issue or ping me on X (@yourhandle).
